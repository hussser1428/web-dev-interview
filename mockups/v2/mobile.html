Các HTTP method khác nhau thế nào? "Safe" và "idempotent" là gì?

Tự trả lờiĐáp ánFollow-up (2)
TRẢ LỜI 30 GIÂY
GET đọc, POST tạo, PUT thay toàn bộ, PATCH sửa một phần, DELETE xoá. Safe = không đổi dữ liệu. Idempotent = gọi nhiều lần như một lần (GET, PUT, DELETE).
http
PUT  /users/42  # 3 lần → như nhau
POST /orders    # 3 lần → 3 đơn
Mẹo ghi điểm: nhắc tới Idempotency-Key khi làm thanh toán.
